# Hi, I'm Calvin Hendra 👋

Full-stack software and AI engineer building production-ready AI products at **PT Bati Investasi Teknologi**.

I own the end-to-end development of **Bati Agent** — an AI-powered sales widget embedded into Shopify storefronts via script injection, featuring NLP semantic search in Bahasa Indonesia and a personalised product recommendation engine. The product is live at **5 Indonesian fashion brands** (Cotton Ink, Torch, KamiIdea, Hijab Chic Store, Russ Simple Life), serving ~**10,000 daily sessions** and delivering a **30–40% conversion rate uplift** for the first client.

I work across the full stack: LLM/RAG pipelines, multi-tenant backend APIs, frontend interfaces, ETL pipelines, and cloud deployment — with every change going through code review.

---

## 🔧 What I'm Working On

**Bati Agent — AI Sales Widget SaaS**
- Script-injected Embed SDK (tsup bundle) deployed to live Shopify storefronts
- AI search pipeline: intent classification → hybrid text-to-SQL + Qdrant vector search → streaming SSE
- Multi-tenant FastAPI backend with PostgreSQL, Redis, and ClickHouse analytics
- Node.js ETL via Shopify GraphQL Bulk Operations for daily data sync
- Deployed on AWS EC2 via Docker Compose + Caddy, with GitHub Actions CI/CD

**BatiLabs Web**
- Company landing page and client onboarding portal (React + Vite)
- Full onboarding flow: Shopify integration, script installation, Xendit payment
- Deployed on AWS S3 + Cloudflare
